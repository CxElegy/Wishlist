小元素の管理：押して「どうしたい？」を選ぶ

← テストグラウンドの入口

使い方（見本）

  1. 版面を選び、気になる小元素を押す。
  2. 「どうしたい？」を 3 つから選ぶ：同じ人の別の写真に替える・この写真で固定・この人ごと外す。
  3. 人数が足りない版面は、頭の「＋ 人を足す」から今いない人を選んで足す（名前で探すこともできる）。
  4. 下の帯の「送る」で、まとめて依頼。替える写真は次の後台作業（1 時間以内）か「今すぐ」で探す。

※ 見本：送っても本番は変わりません。「候補から選ぶ」の写真は同じ画像の位置をずらした仮のものです。

どの写真に？

候補は押したときに集めて、数分で並びます（見本では仮の写真）。

今の写真のどこがだめ？（任意・今後の規則の手がかり）

なぜ？（ひとつ選ぶ）
