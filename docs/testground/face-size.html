なぜ聞くか大きさの基準は「全身」「胸像」「ロゴ」「物」で別々に決めます。どれに入れるかを機械が間違えると、基準そのものがずれるので、いちばん下のここから確かめます。

今どうなっている今の本番：胸像 156 枚の顔は 13〜56px、全身 127 枚の顔は 8〜94px（最大÷最小 4.4 倍と 12.0 倍）。ロゴ 14 枚・物や生き物 97 枚は顔を測らない。　下に 394 枚すべてを自動の分類つきで並べました。

答えで何が変わる押して直した分類は、2 段目以降の見本と、本番の大きさの規則（emblem_face.face_class）の入力になります。直さなければ今の分類のまま次へ進みます。

使い方：絵を押すと分類が 胸像 → 全身 → ロゴ → 物・生き物 の順に変わります（桃色の枠＝あなたが直したもの）。全部見終わったら右上の「この段を保存」。

2 段目（顔の枠）以降は、この段を保存してから開きます。
