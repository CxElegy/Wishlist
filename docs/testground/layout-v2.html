審査待ち（並べ方）

並べ方の「今の本番」と「新しい並べ方」

なぜ聞くか頼まれたのは並べ方のロジック（空白・同じ記事の二度出し・写真の大きさ・押した所へ行く）で、見た目の方向ではありません。前の見本（新聞・雑誌・P5 の 3 案）は、見た目を聞いてしまっていたので外しました。

今の見た目見た目は今の P5（太い枠・硬い影・傾けた札）のまま。下は、指摘のあった場所ごとの「今の本番」（左）と「新しい並べ方」（右）です。「穴」は、カードのすき間（約 40px）より大きい空きの面積の割合です。「新しい並べ方」は先頭に出す記事の数を増やしています（その数だけは一番下で別に聞きます）。

直した規則同じ記事・同じ写真はページ全体で 1 回だけ・升目の最後の段に穴を作らない・右の列は先頭の高さにそろえ、余った高さは写真が引き受ける・写真のない記事は字だけの札。場所ごとに、効いた所だけ数字が動きます（前から小さい所は「差なし」と書きます）。

この見本に無いものiPhone の版面・ゼルダ／モンハンの小元素・スマホの一覧の個別の画面は、お客さま（test-a）の版面で店長のページに無いため、この見本の範囲外（BACKLOG に次の段として残した）。

答えで何が変わるか○ なら、本番のこの場所を新しい並べ方に入れ替えます（全部の版面・店長とお客さま共通の規則）。× なら、そこだけ直して作り直します。本番の写真は無料の枠の都合で灰色の所があります。
