# 小元素（emblem）

## 小元素（原「管理ページ」の一部）

- **小元素の「違う」（2026-10-21，用户定的）**：「版面ごとの状態」の小元素（行のサムネ・「小元素の探し方」の中）を押す → **理由を選ぶ**（`emblem_rules.REJECT_REASONS` の 10 種＋ひとこと）→ 下の帯の「外す」。
  版面ごとに `submit_item` の edit ＋ `{_emblem_reject: [{image, reason, note}]}`（DB の変更なし）→ `requests.yml` の `take-items` が `digest.reject_emblems` で items.yaml から外し、元の画像を `emblem_reject` に（二度と自動で選ばない）、倉庫の webp も消す。足りなくなった分は次の後台で別の画像。
  **理由は今後の規則の手がかり**：`state/emblem_rejects.json` に理由・取り方（why）・網域・種類と一緒に残り、管理ページ「「違う」の理由」で数える。同じ理由・同じ取り方が溜まったら、`REJECT_REASONS` の 3 つ目（近い判断）を締める。規則がまだない理由（「そのほか」）が溜まったら `rules()` に 1 行足す。
- **胸像への入れ替えに質の下限（2026-10-27，用户指摘：BLEACH の一護が 372×519 の顔のアップから 146×225 のぼやけた胸像に替わった）**：`emblem.better_cut`。候補の短い辺 ≥ 256px（`BUST_MIN_SIDE`）・顔の鋭さ ≥ `SHARP_MIN`、入れ替えは元の画像より短い辺もぼけも悪くならないときだけ（元が下限未満なら候補が下限以上で足りる）。満たさない候補は取らず次の候補、なければ回数を増やす（`stage_closeups`・`library_emblem.stage_holds`）。点検 `emb_check` E18 が短い辺 <256px の数を出す。
- **全身还是半身（用户定的）**：游戏・动画的官方立绘（原图透明背景）先按全身测量，再裁成上半身（`emblem.bust_from_body`：从眼睛往下「眼睛到脚底」的 40%，腰附近）——全身贴纸太小看不清脸；**只有正常人体比例才裁**（`emblem.real_body`：姿势模型量腰的位置，腰在「头顶到脚底」60% 以上 = 正常比例；3D 卡通・Q 版大头（腰更低）、动物・吉祥物（姿势模型认不出人体，あつ森的居民・ポチタ）保持全身，用户定的）；
  照片・漫画格子・视频画面按脸裁成半身（`emblem.want_full`）。
  测量：「眼睛到脚底」长度每个角色一样（裁后脚底在图外，网页仍按这个长度缩放 → 体的同一处切开、脸和其他半身像一样大）、按重心对齐（`body_marks`：YOLOv8m-pose 找眼睛和脚踝，从脚踝往下找脚底；尾巴・武器・裙摆・台座不算脚；蹲着的按面积量）。
  Logo 不裁（去掉纯色底存进仓库）；作品主图若是纯文字标题 logo（The Mandalorian）不做卡片，去底后当 logo 贴、横长的按宽度放大（`emblem.wordmark_local` / `render.WIDE_LOGO`）；卡片只在比例接近 4:5 时裁。**只改规则、从头重跑，不单独修某一张图**。
  **实拍作品贴角色的样子（用户定的）**：剧・电影不用演员生活照，用角色页的剧照・作品视频的画面（`emblem_fill.gather_roles`，演员照片只做人脸比对的基准），不够时补作品海报。
  **頭が切れた・ぼやけたものは出さない（2026-10-25，用户指摘）**：切り抜きの上 3px に人物が横幅の 20% 以上＝頭のてっぺんが切れている → 顔が全部入っていても使わない（`emblem.head_cut`）。写真は顔の幅 80px 未満・顔の輪郭の鋭さ 1.0 未満（拡大した剧照）を使わない（`emblem.face_sharp`）。前からの小元素も `drop_broken` で外して次の候補へ、お客さまは `library_emblem.RULES` 7 で作り直し。
  **形の健康（2026-10-25，用户指摘「这图裁的很有问题」：哈利波特剧集の黒い服の男の人、右下が四角く切れて体が途中で終わる）**：まっすぐな切り口は**下の端だけ**許す（`scripts/cutshape.py`・`emblem.trim_flat`）。左右の端にそって人物が高さの 15% を超えてまっすぐ続く（下の 35% の肩の所も数える）→ 切り口が始まる行で下を切り落として半身にする（残り 40% 以上・顔の下まで届くとき。顔の大きさをそろえる `face_fit` の横の切り口も同じ）、直せなければ使わず次の候補。上の端に横幅の 25% を超えて直線、面積 ÷ 凸包 < 0.45（凹みすぎ）も使わない。端にそった細い杖・剣、丸い輪郭は数えない。前からの小元素は `emblem_fill.repair_flat` が半身に直し、直せないものは `drop_broken` が外す（`BROKEN_V` 4、お客さまの版面は `bv` が古いので 1 回見直す）。点検は `harness/emb_check.py` E12。斜めの直線（肩・服の縁）は測らない（自然な肩と区別できない）。
  横长・躺着的形象（高 < 宽×1.3）不量身高不裁，整张显示；全身显示高度有上限。
  管理页「小元素の判断の例」用真实图片放「前 → 後」对比（`emblem_rules.EXAMPLES`，图在 `docs/emblems/examples/`）：加新判断或修了一个坏例子时，把那次的前后图也放进去。
- **版面の顔に出す小元素は知られている順の上位だけ（2026-10-26，用户定的：BLEACH Mirrors High に雀部長次郎が出て「脇役過ぎた」）**：`render._emblem` は名簿の順（`emblem_fill` が並べる）の先頭から `EMB_TOP`（12）か集まった枚数の 2 割の多いほうだけを `data-alts` に入れ、`EMB_JS` は開いて最初に出す 1 枚を上位 3 人から選ぶ。脇役は管理ページの一覧に残る。「ゲームで使えるキャラ（Playable characters）を先に」は未実装（BACKLOG）。
- **小元素（emblem）**：每个版面右上的贴纸。规矩（种类 → 目标枚数 → 取法的顺序 → 本人确认）在 `scripts/emblem_fill.py`、`scripts/face_id.py`，说明在 `TEMPLATES.md`；
  **选图先想「下一层」**：类别・题材（MMORPG 新作、猫用品、滑雪）贴的是它下面的具体作品 / 品牌 / 选手（`emblem_examples`，我喜欢的放第一个，例：剑灵），
  记号（Twemoji）只垫底。角色不用漫画格子・截图，先找官方立绘 / 插画；抠图后上边缘一半以上是人（连框切的特写）就不用；
  **枚数的上限由内容的主要元素数决定**（用户定的，不只是游戏）：1 个元素 1 张，天井 200（用户定的：主要角色全员，绝区零 60 人就 60 张；一次后台只补 10 人 `emblem_fill.STEP`，慢慢补齐）——角色多的游戏有多少角色就多少张、主角 4 人的动画 4 张、5 人团 5 张、
  主题按代表作数。元素数是 `emblem_pool`（`emblem_fill.py --roster` 从 `emblem_category` 分类或 AniList 主角数出来，并补名字）；
  **名簿は全部の版面で規則から（2026-10-25，用户定的「連動して直す」）**：分類は手で書かなくても `find_sources` が探す（作品の名前の付いた分類 → その作品の wiki の Characters など）、AniList の番号があっても分類が先、実写は Wikidata の出演者（P161）。そろった版面も `NAMES_V` が上がれば 1 回数え直す（店長もお客さまも同じ）；
  管理页「小元素」列出每个版面的种类・目标・现有枚数，没到目标的 AI 编辑会自动补（`python scripts/emblem_fill.py --audit`）。
- **お客さまの版面の小元素（2026-10-24，用户定的）**：店長と同じ `emblem_fill.fill_one` を、ライブラリの版面ごとに 1 回（`scripts/library_emblem.py`・`library_emblem.yml`、15 分ごとの見回り〔`--check` で待ちがなければ重い道具を入れずに終わる〕＋待ちが残って 1 版面でも増えたなら自分で次の回を起こす〔空になるまで・chain 20 回まで、2026-10-29〕）。版面 1 つだけの items.yaml を一時の場所に作って走らせる（本物の items.yaml に触れない）。種類は規則（`kind_for`：グループ → group・人（Wikidata P31=Q5）・演出のソロ → person・游戏/影视 → character・好物 → brand・ほか → topic）。題材（topic）は記号も規則で（`icons_for`：名前・小分類の言葉 → Twemoji、当たらなければ板块の記号）、Wikidata の画像は版面の番号で直接引き、字だけ・説明の図・1950 年より前の写真や絵はファイル名で外す（`emblem_fill.not_emblem`）。Commons で探すロゴはロゴのファイルで、名前とロゴの言葉のほかに何も残らないものだけ（`emblem_fill.own_logo`）。ロゴ（P154）のない製品は Wikidata の代表画像（P18）。キャラの名簿は分類の続き・参照 500 超えも数え、分類の説明の記事と下位のページを除く（`emblem.category_top`）。規則の版（`RULES`）を上げると済みの版面も作り直す（`REDO`）。画像は Supabase Storage の公開の箱 `emblems`（`db/emblems.sql`、ファイル名は番号と指紋だけ）、結果は `boards.config.emblem`、`user_pages.py` がそれを版面に。ログ・帯に版面の名前を出さない。
- **顔の大きさは表示でそろえる（2026-10-27，用户 3 回目の指摘）**：`scripts/emblem_face.py`。全部の人物の小元素に `face: [fs, top, fx, mx, w, h]`（`measure_item` が `emblem_fill.drop_broken` のたびに測る）。表示は顔の高さ = 枠の 32%・目の線 30%・頭の上の余白 6〜14%、拡大 1.6 倍・縮小 0.5 倍まで（`fit`・`view`）。そろいきらないもの（全身で顔が小さい・アップ）は管理ページの一覧に札を出す＝選び方で替える対象。店長の版面・お客さまの版面・管理ページの一覧が同じ関数。顔なし（物・生き物）は大きさそのまま。点検：tests/test_emblem_face・emb_check E13。
