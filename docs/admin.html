  2. 2目標に届いている？Claude（AI 編集）

    emblem_kind（なければ type から推定）。人物の多いものは最大 10 枚、ふつうは 6 枚まで。

    person 本人
    別の写真 6（3〜10）
    group グループ

    character キャラ・出演者
    6（3〜10。emblem_who で挙げた全員）
    brand ブランド

    ロゴ・トロフィー・ボール・場所 3（2〜5）
  4. 4候補を集める（上から順、足りるまで）Claude（AI 編集）
