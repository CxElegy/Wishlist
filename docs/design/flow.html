附录 · GitHub 的限制
官方规则 vs 我们的用量（按一个关注项估算）。全部在安全范围内
仓库大小安全 官方我们 建议 < 1 GB，强烈建议 < 5 GB（软上限）每年约 12 MB 数据 + 100–200 MB 历史 单个文件 > 50 MB 警告，> 100 MB 拒收单个文件最大几十 KB “报道过的”只看 14 天 · 通知记录留 30 天 · 网页上的消息永久保留
GitHub Pages（网页）安全 官方我们 网站 ≤ 1 GB所有期都保留，几 MB 流量每月 100 GB（软上限）一个人看，用不完 构建每小时 10 次（软上限）每小时最多 1–2 次
GitHub Actions（定时任务）已处理 官方我们 公开仓库免费，不限分钟每次约 2–3 分钟 连续 60 天没活动 → 定时任务被悄悄停用作品长期没消息时会中招 → 每周一写心跳文件提交一次，永远到不了 60 天
